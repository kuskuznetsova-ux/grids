# GridBubbleHider (Revit add-in)

Команда: у оси переключает конец с **3D на 2D** на текущем виде и затем **скрывает кружок** оси.

## Использование
Вкладка **Оси** -> кнопка **Скрыть кружок**. Нажмите её и кликайте по осям одну за другой:
у конца, ближе к которому кликнули, кружок скрывается (3D переводится в 2D); если кружка там уже нет - он возвращается, конец остаётся 2D. `Esc` - выход.
Оси, выделенные до нажатия кнопки, обрабатываются сразу (все их 3D-концы).

## Сборка и установка
Подходит для Revit 2022, 2023, 2024 (.NET Framework 4.8, один и тот же код). Укажите папку нужной версии:
```
dotnet build -c Release -p:RevitDir="C:\Program Files\Autodesk\Revit 2022"
```
Скопируйте `GridBubbleHider.dll` и `GridBubbleHider.addin` в
`%AppData%\Autodesk\Revit\Addins\2022\` (для другой версии - в папку с её годом; в `.addin` при необходимости укажите полный путь к dll).
Для Revit 2025+ смените `TargetFramework` на `net8.0-windows`.
